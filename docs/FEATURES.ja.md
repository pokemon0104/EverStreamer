# 機能の詳しい説明(日本語)

> 各機能の細かい設定の説明です(日本語のみ)。全体の使い方は [README.ja.md](../README.ja.md) を見てください。

## 3. 使い方

管理画面は3列です。左がタブ、中央がプレビュー、右が選択中パネルの設定です。

### 上部バー
- **配信開始**:経過時間の計測を始めます。停止・再開・リセット、±1分の補正ができます。
  時刻を入れて「開始時刻に合わせる」を押すと、実際の配信開始時刻から測り直します。
- **全体の文字**:すべての文字サイズを一括で拡大・縮小します(80%〜150%、±5%ずつ)。

### プレビュー
- 表示の切り替え:「画面に合わせる」「実寸 100%」「PC視聴 854px」「スマホ視聴 390px」
- 右上の「最小の文字」は、一番小さい文字が視聴者の画面で何 px に見えるかの目安です。
  - PC は 1280px 幅のプレーヤー、スマホは横持ちの全画面で計算しています
  - スマホで 10px 未満なら「やや小さい」、8px 未満なら「小さすぎ」と表示します
  - 初期設定の小さめの文字(コメント欄など)は「小さすぎ」と出ます。「全体の文字」で調整してください
- パネルをクリックすると選択されます
- 「サイドバー」タブをドラッグするとサイドバーが移動し、点線の辺をドラッグするとサイズが変わります
- 選択中パネルの下辺をドラッグすると、そのパネルの高さを固定できます
- 自由配置のパネルは、そのままドラッグで移動できます
- `Shift` を押しながらドラッグすると、10px 単位で動きます

### タブ
| タブ | できること |
|---|---|
| 演出 | いいね・コメント・言葉に反応する演出の種類・場所・大きさ・効果音、テスト再生 |
| コメント連動 | テストコメント、カウンターのボタンと Stream Deck 用 URL |
| お祝い | 登録者の増加・目標達成のお祝いの設定とテスト |
| 背景 | 背景の種類・場所・ゲーム映像の枠・アップロード |
| 感謝 | 感謝メッセージの登録・編集、エンディングセットの再生、表示のしかた、Stream Deck 用の URL |
| パネル | パネルの追加・複製・削除、表示の切り替え(目のアイコン)、ドラッグでの並べ替え |
| ゲーム | ゲームプロファイルの切り替え・保存、タイトル、方式A/B、おまかせ、ロゴのアップロード |
| レイアウト | 3種類の初期レイアウトと自作レイアウトの切り替え・保存、サイドバーの位置・幅・高さ・隙間・余白、アバター用の空き |
| プリセット | 全パネルとレイアウトの構成に名前を付けて保存・読み込み |

### 右側(パネルの設定)
- **内容**:見出し・本文・数値など。種類によって項目が変わります
- **配置とサイズ**
  - サイドバー内に置くか、自由配置にするか
  - 幅・高さ:高さは「自動」なら文字量に合わせて伸び、「固定」なら収まらない分の文字が縮みます
  - 次のパネルと横並びにする/残りのスペースを埋める
- **文字サイズと余白**:見出し・本文・数字のサイズ、行間、文字間隔、内側の余白
- **スタイル**:選ぶと枠・背景・文字装飾がまとめて切り替わります(文字サイズは維持)
- **枠と背景/文字装飾**:スタイルを選んだあとの個別調整
- **アニメーション**:表示・非表示のときの動き。「動きを確認」で試せます

### はみ出しを防ぐ仕組み
1. 高さ固定のパネルは、収まるまで文字を縮めます
2. ゲームタイトルは1行に収まるよう縮め、縮めすぎになる場合は折り返します
3. サイドバー全体に収まらない場合は、サイドバー内の文字を一律で縮めます(レイアウトタブに縮小率を表示)
4. コメント欄は文字を縮めず、古いコメントを上から隠します

## 3-2. YouTube 連携(横配信+縦配信の合算)

横配信と縦配信の数値を YouTube から自動で取得し、数値パネルに合計を表示します。

### APIキーの取得(最初の1回だけ・無料)
1. https://console.cloud.google.com/ に Google アカウントでログインします
2. 画面上部のプロジェクト選択から「新しいプロジェクト」を作ります(名前は自由。例:everstreamer)
3. 左上のメニュー →「APIとサービス」→「ライブラリ」で「YouTube Data API v3」を検索し、「有効にする」を押します
4. 「APIとサービス」→「認証情報」→「認証情報を作成」→「APIキー」を選びます。表示されたキー(`AIza…`)をコピーします
5. おすすめ:作成したキーの「キーを制限」で、「APIの制限」を「YouTube Data API v3」だけにします
6. 管理画面の「YouTube」タブにキーを貼り付けて「保存」を押します

キーは `data/youtube-key.json` にだけ保存され、オーバーレイや管理画面には送られません(画面には先頭と末尾の4文字だけ表示)。
配信で画面共有するときも、キーそのものが映ることはありません。

### 配信ごとの操作
1. 横配信・縦配信を YouTube で開始(または枠を作成)します
2. 「YouTube」タブの「横配信」「縦配信」に、それぞれの配信ページの URL を貼って「反映」を押します
   - 使える形式:`youtube.com/live/…`、`youtube.com/watch?v=…`、`youtu.be/…`、`youtube.com/shorts/…`
   - 片方だけの配信なら、もう片方は空欄で構いません
   - 配信ごとに URL が変わるため、毎回貼り替えが必要です
3. 「▶ 取得を開始」を押します。以後、自動で更新されます(サーバーを再起動しても取得中のまま再開します)
4. 数値パネルは、「取得を開始」を押した時点で自動的に YouTube 連動になります(ラベルが「いいね」「コメント」「登録者」「視聴」などのパネル)。連動の設定は保存されるので、次の配信でも操作は要りません。
   - パネルの「数値の取得」で「手入力」を自分で選んだものは、自動では連動しません
   - 取得中に数値パネルを足したときは、「数値パネルを今すぐ連動にする」ボタンを押すとすぐ連動します

### 取得できる数値
| 指標 | 内容 |
|---|---|
| 同時視聴者数 | 配信中のみ |
| 視聴回数 | 動画の総再生回数 |
| 高評価(いいね) | 高評価を非公開にしている場合は取得できません |
| ライブチャット数 | チャット・スーパーチャットの件数(API が返すチャットを、このツールが数えます) |
| コメント欄の件数 | 動画のコメント欄の件数(ライブ中は通常 0) |
| チャンネル登録者数 | YouTube の仕様で上3桁に丸められた値。5分ごとに更新。横と縦が同じチャンネルなら二重に数えません |

数値パネルごとに、右側の「数値の取得」で 手入力/YouTube、指標、対象(横+縦の合計/横だけ/縦だけ)を切り替えられます。
「目標まで あと何」の表示では、「現在」の値が YouTube の数値になります。

### 数値の扱い(すでに付いている数値も取得します)
URL を登録すると、その動画に**すでに付いている**高評価・視聴回数などを、そのまま表示します(「取得を開始」を押す前でも、URL を反映した時点で1回取得します)。
配信中は、その数値に新しい高評価・チャットが加わっていきます。

- 「YouTube」タブの「数値をゼロに戻す」を押したときだけ、いま付いている数値を基準にして、**そこからの増加分**を表示します(登録者数は除く)
- APIキーを保存したときは、数値を取り直します(ゼロにはなりません)
- 配信のたびに URL を貼り替えれば、新しい動画の数値で表示されます
- **チャンネル登録者数**は、ゼロに戻さず YouTube の値を表示し続けます。同時視聴者数も、その時点の人数です
- サーバーを再起動しても、取得中のまま再開し、数値は引き継がれます

### リアルタイム性と API の利用上限(クォータ)
YouTube Data API は 1 日 10,000 ユニットまで無料で使えます(太平洋時間の 0 時、日本時間の 16〜17 時にリセット)。
更新の間隔は、「YouTube」タブの「更新モード」で選びます。

- **自動(リアルタイム優先・初期設定)**:想定する配信時間(初期 4 時間)に合わせて、無料枠を使い切らない範囲で一番短い間隔にします。
  配信中も使用量に応じて調整し直します。高評価・視聴者数は 5 秒ごと(1 時間あたり約 720 ユニット)、チャット数は残りの枠で決まります(横縦 2 本・4 時間で約 23 秒ごと、1 本だけなら約 12 秒ごと)
- **手動**:高評価・視聴者数は 3 秒〜1 分、チャット数は 10 秒〜1 分の間で指定します

実際の間隔と、1 時間あたりの使用量の目安は、タブに表示されます。

使用量をおさえるための仕組みです。

- **ライブ配信中でない動画は、取得をゆっくりにします**(配信が終わった動画は 60 秒ごと、配信前は 30 秒ごと)。ライブチャットの確認は、ライブ配信中だけ行います
- **想定を大きく超えて使った場合は、自動で取得を止めます**(直近 1 時間で、想定の 2 倍または 2,500 ユニットを超えたとき)。理由がタブに表示され、「取得を開始」で再開できます
- 取得は配信ごとに常に 1 本だけ動きます(URL の貼り替えや「今すぐ更新」で増えません)

**ツールの動作確認や調整をするときは、「取得を開始」を押さないでください**(押さなければ、数値は更新されません)。数値パネルの見た目や動きは、手入力の値で確認できます。
実際の使用量は、Google Cloud Console の「APIとサービス」→「YouTube Data API v3」→「割り当て」でも確認できます。
無料枠を使い切ると取得が自動で止まり、タブにメッセージが表示されます。長時間配信する日は、想定する配信時間を長くするか、「ライブチャットの件数を数える」をオフにすると、残りの更新が速くなります。

YouTube 側の仕様で、高評価や視聴回数が API に反映されるまで、数秒〜数十秒の遅れが出ることがあります。これはこのツールでは短縮できません。
ライブチャット数は、API が返すチャットを数えるため、API が返す範囲より古いチャットは数えられない場合があります。

## 3-3. 登録者目標のバーと動き

「目標まで あと何」の数値パネル(登録者目標など)は、あと何人かをバーでも表示できます。パネルを選び、右側の「数値の内容」で設定します。

### 表示の種類
| 表示 | 内容 |
|---|---|
| 文字だけ | 「500人まで あと71人」のみ |
| 文字+バー(初期設定) | 文字の下に、進み具合のバーと「現在 / 目標」「◯%」 |
| バーだけ | バーと「あと◯人」「◯%」 |
| 交互に切替 | 文字の画面とバーの画面が、設定した秒数ごとに切り替わります(同じ場所で2つ見せられるので、省スペースになります) |

- **バーの0%の値**:例えば前回の目標が 400 人なら 400 にします。400〜500 人の間の進み具合になり、バーが動いて見えます(0 のままだと 0〜500 人の割合で、常に長く表示されます)
- **バーの形**:なめらか/ブロック(区切りのあるゲージ。ブロック数を指定できます)
- **バーの太さ・色・背景色・下の文字**:それぞれ変更できます

### 動き
- 数字は、数が変わるとカウントアップ(ダウン)します。「あと72人」→「あと71人」のように、順番に変わります
- バーは、いまの長さから新しい長さまでなめらかに伸びます
- 数が増えたときは、バーが光り、数字が一瞬大きくなります
- 動きの時間は 0.1〜5 秒で調整でき、それぞれオフにもできます
- 「動きを確認(現在値を+1)」で、手入力のパネルの動きを試せます(YouTube 連動のときは、実際に数値が変わると動きます)

### 数字の大きさ
数値パネルの「数字の大きさ」で、数字(あと◯人の「◯」)、補足(「500人まで」)、ラベルの大きさと、数字だけのフォントを変更できます。
パネルに収まらない場合は、自動で縮小されます。

## 3-4. アバターなどの置き場所を空ける

配信画面の右下(または左下)にアバターを置く場合は、「レイアウト」タブの「アバター用の空き」で、アバターの大きさ(幅・高さ)と場所を入力します。

- 管理画面のプレビューに、アバターの目安の枠(緑)が表示されます。OBS のオーバーレイには表示されません
- サイドバーと重なっている間は、枠が赤になります
- 「アバターに被らないようサイドバーを調整」を押すと、サイドバーの高さ(下部バーなら幅)を、枠に被らないところまで縮めます
- 縮めた分に入りきらないパネルは、文字が自動で小さくなります。小さくなりすぎるときは、メッセージが出ます。そのときは、コメント欄を隠す、数字や余白を小さくする、パネルを減らす、などで調整してください

## 3-5. いいね・コメントを受け取ったときの演出

YouTube の取得中に、いいねやコメントが増えると、カウントと同時に演出を再生します。設定は「演出」タブで行います。
演出の再生に API は使わないので、利用上限の消費は増えません。

| 受け取るもの | 演出の種類 |
|---|---|
| いいね | ハート浮遊(初期)/星きらきら/光るチップ/花火/紙吹雪/+1 ポップ/パネル発光のみ |
| コメント | 吹き出しポップ(初期)/流れるテロップ/お知らせカード/パネル発光のみ |

- **表示する場所**:数値パネルのそば/指定した範囲(X・Y・幅・高さ)/画面全体。指定した範囲は、アバターの枠に被らないところにしてください
- **大きさ**と**一度に出す最大数**(いいね)、**同時に出す最大数**(コメント)を変えられます。いいねが上限より多く増えたときは、「+N」でまとめて表示します
- **コメントの名前と本文**:表示するかどうかを選べます。スーパーチャットは金色の枠と金額つきで表示します
- **効果音**:やわらかいチャイムの短い音を鳴らせます。OBS 用の画面でだけ鳴ります。OBS のブラウザソースの設定で「OBSで音声を制御する」をオンにしてください
- **テスト再生**:YouTube なしで動きを確認できます(プレビューと OBS の両方に表示されます)

注意点です。
- いいね数は合計しか取れないため、前回の取得から増えた数だけ、まとめて再生します
- YouTube 側の反映と取得の間隔があるので、押された瞬間ではなく、数秒〜数十秒後に再生されます。コメントはまとめて届いた分を、少しずつずらして再生します
- URL を登録した直後や「数値をゼロに戻す」の直後の最初の取得、取得を始めたときに返ってくる古いチャットでは、演出しません

## 3-6. 配信終了時の感謝メッセージ

上部の「🙏 感謝を表示」ボタンを押すと、画面いっぱいに感謝のメッセージを表示します。表示中は「■ 感謝を消す」に変わります。設定は「感謝」タブで行います。

- **エンディングセット**:「セットに入れる」がオンのメッセージを上から順に表示し、最後に「今日の記録」(配信時間・最大同時視聴者・高評価・チャット数のうち、取れているもの)を表示します。最後まで終わると自動で消えます
- **これだけ表示**:メッセージを1つだけ表示します(初期は 8 秒)
- **メッセージ**:初期登録は「ありがとうございました」「明日も素晴らしい一日を」「また遊びに来てね」「見てくれてありがとう!」。追加・編集・並べ替え・削除ができ、改行で2行にできます。文字の見た目は、ゲームタイトルの「おまかせ」と同じ 13 種類から選べます。文字は画面に収まる一番大きなサイズに自動で合わせます
- **表示のしかた**:登場の動き(ポップ/ズーム/1文字ずつ/下からスライド/ポップ+きらっ)、いっしょに出す効果(紙吹雪/花火/両方/なし)、暗幕の濃さ、表示時間を選べます
- **表示中はサイドバーを隠す**(初期はオン)、**アバターの枠を避けて表示する**(初期はオフ)、**最後の画面を消さずに残す**を選べます
- **誤操作防止**:「2回押さないと表示しない」をオンにすると、1回目でボタンが「もう一度押すと表示」に変わり、3 秒以内にもう一度押すと表示します

### Stream Deck・スマホから押す
「感謝」タブに、呼び出し用の URL が表示されます(合言葉 token つき)。

| URL | 動き |
|---|---|
| `/api/thanks/play?token=…` | エンディングセットを再生 |
| `/api/thanks/show?n=1&token=…` | n 番目のメッセージを表示 |
| `/api/thanks/hide?token=…` | 消す |

この PC の中からだけ使えます。Stream Deck の「Webリクエスト」系のプラグインなどに登録してください。URL が漏れた場合は「URLを作り直す」で無効にできます。

## 3-7. 配信開始時刻の自動同期

YouTube の取得を始めると、配信の**実際の開始時刻**(`actualStartTime`)で、経過時間が自動で合います。手動で「配信開始」を押す必要はありません。追加の API 消費もありません(動画の数値の取得に含まれています)。

- 配信が始まると、経過時間が動き、「LIVE」の表示になります。配信が終わると、その時間で止まります
- 配信前(待機所)は、経過時間は動きません
- 配信の URL を変えると、経過時間は 0 に戻り、新しい配信の開始を検知すると合わせ直します
- 「YouTube」タブの「経過時間を YouTube の配信開始時刻に自動で合わせる」で、オン・オフを切り替えられます。オンの間は、手動の時刻の補正よりも YouTube の時刻が優先されます

## 3-8. コメント連動(投票・アイデア募集・カウンター・言葉の演出)

YouTube のチャットのコメントを使う機能です。「パネル」タブで、種類を選んで追加します。テストは、「コメント連動」タブの「テストコメント」で、YouTube なしで確認できます(API は使いません)。

**共通のきまり**:取得を始める前の古いコメントは、集計・演出の対象にしません。

### 投票(アンケート)
- 候補ごとに「合図の言葉」(カンマ区切り。例:`左,ひだり,left`)を登録します。全角・半角、大文字・小文字は区別しません
- 判定:コメントに含まれていれば(初期)/完全一致のみ
- **1人1票**(初期):同じ人が何度書いても1票です。投票先を変えると、前の票は取り消されます
- 票の多い順の並べ替え、割合(%)の表示、表示する候補数、受付の開始・終了、票のリセットができます
- プリセット:ルート選択/武器・装備/A〜D 選択/はい・いいえ。候補は自由に追加・編集できます
- 票が入ると、バーが伸びて数字が光ります

### アイデア募集
- コメントを一覧にして表示します。「募集の合言葉」(例:`#案`)を決めておくと、その合言葉のコメントだけが集まります(空欄なら全部のコメント)
- 最大の長さ(初期 25 文字)を超えるものは除外します。投稿者名の表示・非表示、表示する件数、削除、全消去ができます

### カウンター
- 「全滅数」「ボス撃破」などを、数字で表示します。名前と数は自由に追加・編集できます
- 「コメント連動」タブのボタンで、配信中に増減できます
- **Stream Deck・スマホから増減**:同じタブに、URL が表示されます(合言葉つき・この PC の中だけ)。`/api/counter?panel=パネル名&n=1&delta=1&token=…` を開くと、1番目のカウンターが +1 されます

### 言葉に反応する演出
「演出」タブの「コメントの言葉に反応する絵文字」で設定します。登録した言葉がコメントに含まれていると、絵文字や文字が舞います。
初期ルール:草(🌱)/8888(👏)/gg・ナイス(🎉)/神・きた(🔥)/セーブ(💾)。ルールは、言葉・絵文字・色を自由に追加・編集できます。
連打で画面が埋まらないよう、同じ言葉の反応の間隔(初期 1.5 秒)と、同時に出す最大数を設定できます。

## 3-9. お祝い(登録者の増加・目標達成)

「お祝い」タブで設定します。YouTube の取得中に、画面いっぱいにお祝いを表示します。API の消費は増えません。

- **チャンネル登録者が増えたとき**:「チャンネル登録ありがとう!」と「+N」、花火・紙吹雪・星・フラッシュ(全部入り)
- **目標を達成したとき**:数値パネル(「目標まで あと何」)の値が増えて目標に届くと、「目標達成!」の大きな文字、回る光線、たくさんの花火・紙吹雪・ハートを表示します(初期 12 秒)
- 文字・補足の文・文字の見た目(ゲームタイトルの「おまかせ」と同じ 13 種類)・演出の種類・表示時間を変えられます。ファンファーレも任意で鳴らせます
- 続けて起きたお祝いは、順番に再生します(例:登録者増加 → 目標達成)
- 「表示する場所」で、画面いっぱい / 登録者目標のパネルのまわりだけ / 両方 を選べます(登録者増加・目標達成それぞれに設定)。パネルのまわりだけの場合は、花火・紙吹雪などがそのパネルの周囲に出て、パネルが光り「+人数」が浮かびます。登録者目標のパネルが見つからないときは、画面いっぱいで代わりに表示します。縦型配信のように画面が狭い場合にも向きます。
- 「試す」ボタンで、すぐに確認できます
- 登録者数は、「YouTube」タブの「登録者数の確認間隔」(初期 30 秒、1 回 1 ユニット)ごとに調べます。増えてから表示されるまで、その間隔ぶん遅れることがあります。YouTube の仕様で、1,000 人を超えると、登録者数は上3桁に丸められます

## 3-10. 背景

「背景」タブで設定します。初期は「表示しない」です。

- **背景の場所**
  - サイドバーの後ろ:サイドバーの範囲に背景を表示します
  - 画面全体(ゲーム映像の枠を抜く):ゲーム映像を表示する場所だけを透明にして、まわりに背景を表示します。場所は、サイドバー以外の範囲に、縦横比(16:9/4:3/1:1)と余白で自動に決めるか、数値で指定します。OBS のゲーム映像を、画面に表示される位置・大きさに置くと、枠の中にぴったり収まります。枠線(実線/二重線)も付けられます
- **背景の種類**
  - テンプレートの背景(初期。テンプレートとメインカラーに合わせて変わる)
  - プリセット(18 種類)
    - シンプル:漆黒/チャコール/ライトグレー/ネイビー
    - グラデーション:ミッドナイト/夕焼け/ネオン/オーロラ/オーシャン/ピーチ/メッシュ/フォレスト
    - パターン:チェック/水玉/斜めストライプ/ネオングリッド/カーボン/斜めライン(細)
  - 単色/グラデーション(2色と角度)
  - 自分の画像・動画:画像は PNG・JPG・WebP・GIF・SVG(25MB まで)、動画は MP4・WebM(300MB まで。音なしでくり返し再生)。`data/backgrounds/` に保存されます
- 画像の合わせ方:全面に広げる/全体を収める/並べる。「暗くする」で、背景が明るすぎるときも文字が読みやすくなります
- プリセットは `config/backgrounds.json` で追加・編集できます

## 4. 初期配置

横画面は、右にパネルを縦に積むサイドバー、左にゲーム映像の場所(テンプレートの枠つき)の配置です。縦画面は、上にゲームタイトルと目的・目標、その下にゲーム映像、横型配信のコメント、縦型配信のコメント用の空きが並びます。どのパネルも「配置とサイズ」で自由配置にすると、プレビュー上でドラッグして動かせます。

## 6. 仕様メモ(後続ステップ向け)

### WebSocket メッセージ
すべてのメッセージは共通の形をしています。

```
{ "type": "名前空間:動作", "payload": { ... }, "seq": 12 }
```

| 方向 | type | 内容 |
|---|---|---|
| 画面→サーバー | `core:hello` | `{role:"overlay"\|"admin"}` |
| サーバー→画面 | `core:init` | `{clientId, version, state, catalogs}` すべての状態 |
| サーバー→全画面 | `core:section` | `{key, value}` 変更のあった設定区分(`origin`/`seq` 付き) |
| サーバー→全画面 | `core:catalog` | `{name, value}` スタイル・ロゴ一覧などの変更 |
| サーバー→送信元 | `core:toast` / `core:error` | 通知 |

機能ごとのメッセージは次のとおりです。

| 名前空間 | 動作 |
|---|---|
| `panels:` | add, update `{id, patch}`, remove, duplicate, reorder `{ids}`, setStyle `{id\|all, styleId}`, resetLook |
| `layout:` | update `{patch}`, apply `{id}`, save `{name}`, remove |
| `game:` | update `{patch}`, omakase, saveProfile, loadProfile, deleteProfile, renameProfile, deleteLogo |
| `timer:` | start, stop, resume, reset, adjust `{deltaMs}`, setStart `{startedAt}` |
| `presets:` | save, load, remove |
| `reactions:` | update `{patch}`, test `{kind: like\|comment\|word, count, rule}`(サーバー→画面:`reactions:fire`) |
| `celebrate:` | update, test `{kind: sub\|goal}`(サーバー→画面:`celebrate:play`) |
| `ct:` | test(テストコメント), resetVotes, clearIdeas, removeIdea, loadPreset, counter, newToken |
| `background:` | update, deleteUpload |
| `thanks:` | playSet, show `{id}`, hide, update, addMessage, updateMessage, removeMessage, moveMessage, newToken |
| `youtube:` | setKey, clearKey, update `{patch:{h:{url}, v:{url}, pollSec, chatCount, chatSec}}`, start, stop, refresh, resetStats, linkPanels |

| `commentBox:` | test `{side: h\|v, count}`, clear |
| `panels:` に追加 | resetAll(初期のパネル構成に戻す。縦画面なら縦型の初期配置) |

`patch` は差分で送ります。値に `null` を入れると、そのキーを削除する指示になります。

縦画面を編集しているときは、管理画面が payload に `canvas: "v"` を付けて送ります。サーバーはこのとき `panels / layout / layoutPresets / presets / background / reactions` を、それぞれ `vPanels / vLayout / vLayoutPresets / vPresets / vBackground / vReactions` に読み替えます(`core/canvas.js`)。各機能は横画面と同じ処理のまま、縦画面に対応します。

### 設定ファイル(data/settings.json)
```
{
  "version": 1,
  "panels": [ { id, type, name, visible, placement, x, y, w, h, widthMode, heightMode,
                pairWithNext, fill, fillMin, styleId, look:{個別調整}, anim:{type, ms}, data:{種類ごと} } ],
  "layout": { globalScale, activeId, container:{enabled, dock, x, y, w, h, gap, margin, direction}, avatar:{show, side, w, h} },
  "layoutPresets": [...], "presets": [...],
  "game": { title, method, lookId, lookLocked, logo, logoShadow, logoGlow, logoGlowColor, hardware:[...], profileId },
  "gameProfiles": [...], "timer": { startedAt, stoppedAt },
  "youtube": { running, pollSec, chatCount, chatSec, hasKey, keyHint, h:{url, videoId}, v:{url, videoId} },
  "ytStats": { updatedAt, error, h:{…}, v:{…}, total:{viewCount, likeCount, …}, quota:{date, units} }
}
```
- パネルの見た目は「styles.json の base → スタイルの look → パネルの look」の順に上書きして決まります
- スキーマを変えるときは `core/store.js` の `MIGRATIONS` に移行処理を追加し、`SCHEMA_VERSION` を上げます

### 新しい機能を足すには(例:字幕)
1. `features/subtitle/` を作り、`server.js` で `sections`(保存する設定)と `handlers`(`subtitle:xxx` メッセージ)を定義します
2. パネルとして出すなら、`panelTypes` と、`overlay.js` の `OV.registerPanelType()` を使います
   全画面に重ねるなら、`OV.registerLayer({ mount, update })` を使います
3. 管理画面は、`admin.js` で `ADM.registerTab()` / `ADM.registerInspector()` を使います
4. 外部 API(YouTube など)は、`server.js` の `init({ app, store, hub })` から呼び出し、`hub.broadcast()` で配信します

数値パネルは `data.source` で取得元を切り替えます。新しい取得元は、overlay.js で `OV.numberSources[名前] = { get(data, state), deps(state) }` を登録すると追加できます(YouTube 連携はこの仕組みで作っています)。

## 7. 定義ファイルの編集

| ファイル | 編集のしかた |
|---|---|
| `config/styles.json` | `styles` に `{ "id", "name", "look": {...} }` を追加すると、スタイル一覧に出ます。`look` に書ける項目は `base` と同じです |
| `config/title-looks.json` | 「おまかせ」の見た目セットを追加できます |
| `config/fonts.json` | Google Fonts の名前と太さを追加できます |

`config/title-looks.json` の項目は次のとおりです。

- `fill`:単色 `{type:"solid", color}`、またはグラデーション `{type:"gradient", angle, stops:[...]}`
- `strokes`:縁取り。内側から外側の順に書くと、何重にも重ねられます
- `glow`/`shadow`:グローと影
- `skew`:傾き(度)
- `italic`:斜体
- `fallbackFont`:英数字専用フォントのときに、日本語に使うフォント

太さ・グロー・影の数値は、文字サイズ 48px を基準にした値で書きます。実際の表示では文字サイズに比例します。

JSON の書き方を間違えた場合は、直前の正しい内容のまま動き続け、サーバーの画面に警告が出ます。

## 8. 困ったとき

| 症状 | 対処 |
|---|---|
| OBS で何も表示されない | `npm start` のウィンドウが開いているか確認し、ブラウザソースの「現在のページのキャッシュを更新」を押す |
| 「クォータを使い切りました」と出た | 1 日の無料枠(10,000)を使い切った状態です。太平洋時間の 0 時(日本時間の 16 時または 17 時)にリセットされるまで、取得できません。それまでは、数値パネルを「手入力」にして調整できます |
| YouTube の数値が出ない | 「YouTube」タブのメッセージを確認。URL が配信ページのものか、APIキーで YouTube Data API v3 が有効になっているかを確認してください |
| フォントが違う | 初回はインターネット接続が必要です。接続後に管理画面を開き直してください |
| 設定を初期状態に戻したい | サーバーを止めて `data/settings.json` を削除します(ロゴは `data/logos/` に残ります) |
| 設定ファイルが壊れた | 自動で `settings.broken-日時.json` に退避し、初期状態で起動します |

字幕(音声認識・音量連動)、コメント連動アンケート、コメント欄パネルへの実際のコメント表示、コメントリアクションは、まだ含めていません。

## 3-11. 数値パネルの見た目(絵文字・演出だけ)と、演出の場所
- 数値パネルの「見た目」で、次の3つから選べます。
  - 文字ラベル:従来どおり「いいね 128」のように文字+数字
  - 絵文字+数字:👍 128 / 💬 54 / 👤 429 のように、絵文字と数字だけ。YouTube連動なら指標から絵文字を自動で選び、好きな絵文字に変えることもできます
  - 演出だけ:数字も文字も枠も表示せず、いいね・コメント・お祝いのアニメーションだけがその場所に出ます(管理画面のプレビューでは点線の枠で場所を示します)。縦型配信のように、YouTube が数字を出してくれている画面向けです
- 縦型の数字は、パネルの「対象」を「縦だけ」にすると、横と同じように出せます。
- 「演出」タブの「表示する場所」を「指定した範囲」にして、「かんたん指定」(左下・右下・左上・右上など)を押すと、画面の好きな隅からいいね・コメントの演出を出せます。X / Y / 幅 / 高さで細かい調整もできます。

## 3-12. 縦型配信(ショート・9:16)の画面

横型配信とは別に、縦型配信用の画面(1080×1920)を作れます。

- 管理画面の上部「編集する画面」で **縦 9:16** を押すと、縦画面の編集に切り替わります(上部に桃色の線が出ます)。戻すときは **横 16:9**
- OBS には `http://localhost:3000/overlay-vertical`(幅 1080 / 高さ 1920)を登録します
- 縦画面だけ別に持つ設定:**パネル・レイアウト・背景・演出(いいね・コメント・言葉)の場所・構成プリセット**
- 横と縦で共通の設定:ゲーム(タイトル・ロゴ・今日の目的・プロファイル)・YouTube・お祝い・感謝・経過時間・投票など

### 縦画面の初期配置(1080×1920)

```
┌──────────────┬──────────────────────┐ y=16
│ ゲームロゴ    │ 今日の目的(リッチテキスト)│ 360×250 / 676×250
├──────────────┴──────────────────────┤ y=282
│                                     │
│     ゲーム映像(OBS側で配置)            │ 1080×810(4:3)
│                                     │
├─────────────────────────────────────┤ y=1108
│ 横型コメント(横型配信のライブチャット)     │ 1048×330
├───────────────────────┬─────────────┤ y=1454
│ 縦型コメント用の空き      │ アバター     │ 628×450 / 400×440(目安)
│(YouTube が表示する場所) │ (目安)      │
└───────────────────────┴─────────────┘ y=1920
```

- いいね・コメント・登録者の数値パネル(絵文字+数字)も入っていますが、YouTube が縦型の画面に数字を出すため、初期は非表示です。パネル一覧の目のマークで表示できます
- レイアウトタブの「縦型の初期配置に戻す」で、いつでもこの配置に戻せます(横画面は変わりません)

### ゲーム映像の場所

レイアウトタブ(縦画面)の「ゲーム映像の場所」で決めます。「横幅いっぱい」のボタンで、16:9 / 4:3 / 3:2 / 1:1 の大きさにすぐ合わせられます。OBS では、ゲーム映像のソースをこの位置・大きさに合わせてください。背景タブで背景を「画面全体」にすると、この部分が抜かれ、枠線も付けられます。

### ゲームロゴ(左上)

パネルの種類「ゲームロゴ」。ロゴ画像を枠いっぱいに、縦横比を保って大きく表示します。

- 「選んでいるゲームのロゴ」:ゲームタブのロゴと同じ。ゲームプロファイルを切り替えると、ロゴも切り替わります
- 「決まったロゴ」:このパネルだけ、決まったロゴを表示
- ロゴがないときは、タイトルの文字を「おまかせ」の見た目で表示します(1行に収まるよう自動で縮小)
- 横画面のゲームタイトルを文字(方式A)にしていても、ロゴを登録しておけば、縦画面ではロゴを表示できます

### 目的・目標(リッチテキスト)

パネルの種類「リッチテキスト(目的・目標など)」。1行ずつ次を選べます。

- 大きさ:小 / 中 / 大 / 特大
- 行頭:記号なし / ▶ / ★ / ♥ / → / 1. 番号 / □ やること / ✔ 済み(線を引く)/ 見出し
- 強調:太字 / マーカー / 光る / 縁取り / 点滅
- 色:8色から(なし=パネルの文字色)
- 文の一部だけ目立たせる:`**ここ**` で強調の色・太字、`==ここ==` でマーカー
- 「まとめて入力」:`# 見出し`、`- 箇条書き`、`* ★`、`[ ] やること`、`[x] 済み`、`1. 番号`、行頭に `!` で大・`!!` で特大

「表示する内容」で「今日の目標」「ゲーム全体の目的」を選ぶと、内容はゲームの設定に保存され、横画面・縦画面で共通になります(詳しくは 3-14)。

### 横型コメント(横型配信のライブチャット)

コメント欄のパネルで「表示するコメント」を選べます:ダミー / 横型配信のチャット / 縦型配信のチャット / 横+縦。

- YouTube タブで取得中のライブチャットを、そのまま表示します(API の消費は増えません)。YouTube タブの「ライブチャット数」がオンのときに届きます
- スーパーチャットは金額付きで目立たせて表示します
- 入りきらない古いコメントは、上から消えます(半分だけ見える行は出しません)
- 最近のコメントはサーバーのメモリにだけ置き、保存はしません(再起動すると空になります)
- テストボタン(横に1件 / 縦に1件)で、YouTube なしでも見た目を確認できます

### 縦型コメント用の空き

パネルの種類「空きスペース(場所取り)」。OBS には何も表示されず、管理画面のプレビューにだけ点線の枠と名前が出ます。YouTube が縦型の画面にコメントを表示する場所など、パネルを置きたくない場所の目安に使います。

### 演出(縦画面)

- いいね・コメント・言葉の演出は、縦画面だけ別の場所・種類にできます(演出タブ)。縦画面の初期は、コメントの演出はオフ(YouTube がコメントを表示するため)、いいねはゲーム映像の右下あたりです
- 演出タブの「かんたん指定」(左下・右下など)は、縦画面では縦画面の大きさで計算されます
- お祝い・感謝メッセージは、縦画面でも画面の大きさに合わせて表示されます。お祝いを「パネルのまわりだけ」にした場合、縦画面に表示中の登録者パネルがなければ、画面いっぱいで表示します

### 見え方チェック(縦画面)

プレビュー上部の「最小の文字」は、縦画面では「PC:縦長で約405px幅」「スマホ:縦持ち全画面で約390px幅」で計算します。1080px の画面がスマホでは約 0.36 倍になるため、本文は 28px 以上を目安にしてください。


## 3-13. ゲーム枠

管理画面の「ゲーム枠」タブ(詳細設定)で、ゲーム映像のまわりを囲む枠を、このオーバーレイが描きます。初期は「テンプレートの枠」を表示します。

- **テンプレートの枠**:クイック設定で選んだテンプレートとメインカラーに合わせて、枠のデザインが変わります。
- **用意した枠**:シンプル(白線)・ミニマル・ガラス・ネオン・グラデーション(夕焼け)・ゴールド・HUD(四隅だけ)・eスポーツ・ダークガラス・パステル・枠なし。
- **パネルも枠と同じデザインに**:パネルの「スタイル」に「ゲーム枠と同じスタイル」があります。「枠の種類にスタイルを合わせる(一括で連動)」ボタンで、まとめて連動できます。
- **枠の調整**:帯(太さ・色・グラデーション)、角丸、縦横比、光・影・四隅のカギ型、連動したパネルの色を変えられます。
- **大きさ・位置を自分で指定**:OBS でゲーム映像ソースを右クリック →「変換」→「変換の編集」の「位置」「サイズ」をそのまま入力すると、枠がぴったり合います。
- **自分の枠画像を取り込む**:枠画像をドロップすると、中央のゲーム映像の黒い部分を自動で見つけて透明にします。
- 枠の定義は `config/game-frames.json` で追加・編集できます。取り込んだ画像は `data/frames/` に保存されます。

## 3-14. ゲーム全体の目的と、今日の目標(横画面・縦画面で共通)

目的を2つに分けました。どちらもゲームの設定に保存され、**横画面と縦画面の両方に同じ内容が表示されます**(1回書けば済みます)。

- **ゲーム全体の目的**:このゲームをどんな目的で配信するか(例:20年ぶりにクリアする)
- **今日の目標**:今日はどこまで進めるか・やること(例:チシャの村に行く)

使い方

- 内容は「ゲーム」タブの「目的と目標(横画面・縦画面で共通)」で書きます。パネルの設定からも編集できます(同じ内容です)。
- 書き換えると、選んでいるゲームプロファイルにも自動で保存されます。ゲームを切り替えて戻ると、前回の目的・目標が引き継がれます。
- パネルは、ゲームタブの「目的・目標のパネル」から「この画面に『ゲーム全体の目的』を追加」「…『今日の目標』を追加」で置けます。リッチテキストのパネルの「表示する内容」でも切り替えられます(このパネルだけ/今日の目標/ゲーム全体の目的)。
- **以前の版から更新した場合**:以前の「今日の目的」は「今日の目標」として引き継ぎます(見出しが「今日の目的」のままなら「今日の目標」に変わります)。「ゲーム全体の目的」は空から始まります。
- **連動していないパネル**(縦画面で別に書いていたパネルや、テキストのパネルで書いた目的)は、ゲームタブの一覧に「連動していない」と表示されます。「今日の目標に連動」「目的に連動」を押すと共通の内容に切り替わります。そのとき、そのパネルの内容を共通の内容として使うか(OK)、捨てて共通の内容を表示するか(キャンセル)を選べます。テキストのパネルは、位置・見た目はそのままでリッチテキストのパネルに変わります。

## 3-15. パネルのグループ(いいね・コメント・登録者を横一列に)

数値パネルなどを1つのグループにまとめ、**横一列に並べて高さと幅をそろえます**。位置と大きさはグループで1回決めるだけです(パネルごとに X・Y を合わせる必要がなくなります)。中のパネルは、それぞれの枠・見た目のままです。

- 作り方:「パネル」タブの「+ いいね・コメント・登録者 を横一列にまとめる」を押します(数値パネルが2つ以上あるとき、その名前がボタンに出ます)。数値パネルがないときは「+ グループを作る」で空のグループができ、あとから追加できます。
- グループの設定:中のパネルの追加・外す・並び順(← →)、パネルごとの幅の比率、すき間、「数字・文字の大きさをそろえる」(1つが縮小されたら、ほかも同じ割合で縮小)、「1つ目のパネルと同じ見た目にそろえる」、「グループを解除」。
- 目標バー・テキストなど、数値パネル以外も入れられます。
- サイドバー内にも、自由配置にも置けます。自由配置のパネルをまとめると、元のパネルを囲む位置に横一列で置きます(縦に並んでいたパネルも横一列になります)。
- プレビューで中のパネルをドラッグすると、グループごと動きます。大きさはグループの「配置とサイズ」で変えます。
- グループを非表示にすると中のパネルもまとめて隠れます。中のパネルを1つ非表示にすると、残りが幅を分け合います。
- 「グループを解除」すると、中のパネルはグループのあった場所に並んだまま、元の個別パネルに戻ります。
- 縦画面でも使えます(横画面・縦画面で別々のグループ)。いいね・コメント・登録者の演出(パネルのまわりの演出)は、グループの中でもそのまま動きます。


## 3-16. あらすじ(配信の前に話すあらすじを、演出つきで表示)

管理画面の「あらすじ」タブと、上部バーの「📖 あらすじ」ボタンで使います。

**文章**
- 「あらすじ」タブに見出しと文章を書きます。「---」だけの行でページを区切ります。`**大事なところ**` で強調の色、`==ここ==` でマーカーになります。
- 文章はゲームの設定に保存され、横画面・縦画面で共通です。ゲームプロファイルにも自動で保存されるので、ゲームを切り替えるとあらすじも切り替わります。

**出し方(トランジション)**
- 見せ方:ページ送り/スクロール(エンドロール。「下から上へ」と、奥へ流れる「宇宙風」)
- 登場・退場のしかた(14種類):ウィンドウが開く、フェード、上下左右からスライド、ズーム、ぼかし、ワイプ、カーテン、シャッター、アイリス(丸く広がる)、シネマ(黒帯が出て、文字が集まる)、なし。時間も変えられます。
- 文字の出し方:タイプライター、1文字ずつふわっと、1行ずつ浮かび上がる、ぼかしから浮かぶ、演出なし(速さ・間隔も調整できます)。
- ページの切り替え:フェード/横にスライド/上に流れる/なし。自動でページを送る(読む時間を秒で指定)か、「次 ▶」で自分のペースで送れます。
- 最後まで行ったら自動で退場/表示中はサイドバー・パネルを隠す、も選べます。

**操作**
- 上部バーの「📖 あらすじ」で表示、もう一度押す(「■ あらすじを終える」)と退場します。表示中は「次へ ▶」も出ます。
- タブでは、前・次・一時停止・終える(退場)・すぐ消す が使えます。
- 「プレビューだけで試す」は、OBS には出さずに、管理画面のプレビューだけで動きを確認できます。

**デザイン**
- 用意したデザイン:テンプレートに合わせる(初期)、映画の字幕風、巻物(和風)、宇宙のエンドロール風、ネオン、絵本、黒帯(字幕)。選ぶと文字・枠・背景がまとめて切り替わります。
- そのあと、フォント(用意したフォントから選択。明朝・筆書きのフォントを追加しました)、大きさ、色、揃え、行間、文字間隔、見出しの飾り、縁取り・影・光、枠の色・グラデーション・枠線・角丸・余白・幅、うしろの暗幕(濃さ・色・ぼかし)を自由に変えられます。
- 「今のデザインを保存」で名前を付けて保存すると、★の付いた自作デザインとして一覧に並びます(上書き・削除もできます)。用意したデザインは `config/story-designs.json` で追加・編集できます。

**表示する場所**(横画面・縦画面で別々)
- 画面全体/ゲーム映像の上/ゲーム映像の下側/数値で指定。まわりの余白、文字と余白の倍率、この画面だけの枠の幅も決められます。文字が多くて収まらないときは、自動で縮小されます。


## 3-17. 背景・ロゴを複数登録して、ゲームごとに切り替える

- 背景(「背景」タブ →「自分の画像」)とロゴ(「ゲーム」タブ →「B ロゴ画像」)は、何枚でも登録できます。ドロップ欄には **複数まとめて** ドロップ/選択できます。登録した画像は一覧に並び、クリックで切り替え、× で削除できます。
- **ゲームごとに自動で切り替え**:ゲームプロファイルを選んでいるときに背景やロゴを選ぶと、そのゲームの背景・ロゴとして自動で保存されます。ゲームを切り替えると、背景・ロゴも一緒に切り替わります(横画面・縦画面の背景は、それぞれ別に保存されます)。
- 背景を連動させたくないときは、背景タブの「ゲームごとに背景を切り替える」をオフにします。
- **上部バーの「ゲーム」**:配信中でも、ここでゲームを選ぶだけで、タイトル・ロゴ・背景・目的/目標・あらすじがまとめて切り替わります(1本の配信で2〜3本のゲームを遊ぶときに便利です)。
- 新しいゲームは、ゲームタブの「今の設定を保存」で名前を付けて追加します。


## 3-18. お願いポップアップ(チャンネル登録・高評価のお願い)

「チャンネル登録お願いします!」などを、好きなタイミングでボタン1つで画面に出します。決めた秒数で消えるので、ずっと出しっぱなしより目に留まりやすくなります。

**出し方**
- 上部バーの 📣 のボタン(「上部バーにボタンを出す」にしたメッセージ)を押すと表示されます。表示中にもう一度押すと消えます。
- 「お願い」タブの「表示」「▶ 配信画面に表示」でも出せます。「プレビューだけで試す」は OBS に出さずに確認できます。
- 「自動で出す間隔(分)」を決めると、「自動で出す」にしたメッセージを順番に自動表示します。
- Stream Deck などからは、タブに出ている呼び出しURL(`/api/callout/show?n=番号&token=…`)で表示できます。

**メッセージごとに決められること**
- 文字(2行目の小さい文字も)、表示する時間
- 登場(ポップ・上から落ちて跳ねる・フェード・上下左右からスライド・ズーム・回転・くるくる・ワイプ・ぼかし・タイプライター)と退場(フェード・しぼむ・小さくなる・スライド・回転・落ちる・ワイプ・ぼかし)
- アイコン:指さし(上下左右)、矢印(上下左右)、流れる矢印、曲がった矢印、👍 🔔 ❤️ 💬 ⭐ ✨。動き(矢印の向きに弾む・大きくなったり小さく・ゆらゆら・ぷるぷる・ベルのように揺れる・回る)、文字との位置、大きさ、色
- 表示する場所:3×3 の基準の位置(左上〜右下)+ずらす量+大きさ。横画面と縦画面で別々に決められます。YouTube の「チャンネル登録」ボタンは、横型配信では動画の左下の下、ショートでは画面の左下にあるので、左下に置いて下向きの矢印・指さしにすると伝わりやすくなります。
- デザイン:テンプレートに合わせる(初期)、赤いボタン風、ネオン(ピンク/シアン)、ゴールドきらきら、虹色、吹き出し、ポップ(黄色)、リボン、黒帯、和風(筆)。選んだあと、フォント・大きさ・太字・文字の色(単色/グラデーション3色まで)・縁取り・影・エフェクト・枠の形・背景色/グラデーション・枠線・角丸・余白を自由に変えられます。
- エフェクト:なし、光る、ネオン(ちらちら光る)、きらきら(星が舞う)、つやが流れる、虹色に変わる、ドクンと脈打つ、ふわふわ浮く、文字が波打つ、ときどき揺れる、点滅
- デザインの一覧は `config/callout-designs.json` で追加・編集できます。

## 3-13. 大きな文字パネル・フォント・SNSアカウント・ゲームごとの画面設定(バージョン 1.1)

### 大きな文字パネル
- 「パネル」タブで「+ パネルを追加」から「大きな文字(自由配置)」を選びます。プレビューでドラッグして移動、右下の角で幅を変えられます。
- 「デザインを選ぶ」で 111 種類のギャラリーが開きます。クリックで適用。迷ったら「🎲 おまかせ」(テーマの中からランダム)。気に入った見た目は「今の見た目をマイデザインに保存」で残せます。
- 文字を選んで「大きく」「小さく」「色1」「色2」を押すと、その部分だけ変えられます(`<< >>` 大きく、`(( ))` 小さく、`[[ ]]` 色1、`{{ }}` 色2)。ひらがなを自動で小さくすることもできます。
- 縁取り(3 段)・グロー・影・立体・グラデーション・質感(写真の模様)・文字の後ろの図形・ふわふわなどの動きを調整できます。
- デザインの一覧は `config/text-designs.json`、質感の画像は `features/bigText/textures/` です。自分の画像を `data/text-textures/` に入れても増やせます。

### フォントタブ
- PC にインストール済みのフォントは、名前を登録するだけで使えます(OBS も同じ PC で動くため)。「PC のフォント一覧を読み込む」で一覧から選べます(Chrome・Edge)。
- フォントファイル(TTF / OTF / WOFF / WOFF2)をドロップすると `data/userfonts/` に保存されます。登録したフォントは、すべてのフォント選択欄に出ます。使うフォントのライセンスは、ご自分で確認してください。

### SNSアカウントパネル
- 複数のアカウントを登録して、「縦に並べる」「横に並べる」「1つずつ切り替え」で表示します。印はサービスの略号(ロゴは使いません)で、色はテンプレートに合わせます。

### ゲームごとの画面設定
- 「ゲーム」タブで「ゲームごとに画面の設定を分ける」をオンにすると、ゲームプロファイルごとにパネル・サイドバー・背景・ゲーム枠・演出などを覚えます。初めて切り替えたゲームは、それまでの画面を引き継ぎます。

### そのほか
- 「見出しを枠線の上に重ねる」(パネルのスタイル): ウィンドウのタイトルのような見出しになります。「全パネルをこの設定にする」で一括変更できます。
- 「レイアウト」タブの「ゲーム映像の場所」は、プレビューの「ゲーム映像」タブをドラッグして動かせます(Shift で 10px 単位)。
- 「YouTube の表示の目安」: YouTube で見たときにチャット欄やボタンが重なる場所を、プレビューだけに赤い点線で表示します(OBS には出ません)。スクリーンショットを重ねて見比べることもできます。
- 「コメント連動」「演出」「感謝」「お祝い」の「出す画面」で、横型・縦型のどちらに出すかを選べます。
